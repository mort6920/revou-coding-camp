# Life Dashboard

Dashboard produktivitas pribadi yang dibuat pakai HTML, CSS, dan JavaScript biasa — tanpa framework, tanpa backend.

🔗 **Live Demo:** [Lihat di GitHub Pages](https://mort6920.github.io/revou-coding-camp)

---

## Fitur

- Jam real-time dengan zona waktu WIB (Jakarta)
- Sapaan otomatis berdasarkan waktu hari
- Timer fokus (Pomodoro) dengan tombol Start, Stop, Reset
- To-do list — tambah, edit, selesaikan, hapus tugas
- Quick links — simpan dan buka website favorit
- Pilihan tema: Light, Original, Dark

## Tantangan nya

- Nama custom di sapaan
- Durasi Pomodoro bisa diubah sendiri (1–60 menit)
- Urutkan tugas (A→Z, Z→A, belum selesai duluan)
